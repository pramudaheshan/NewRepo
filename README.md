# Reservations Management Web App

A minimal reservations management web application built with vanilla HTML/CSS/JavaScript.

## Features
- Add reservations (customer, date, time, party size, notes)
- Edit reservations
- Delete reservations
- Toggle reservation status between Pending and Confirmed
- Persist reservations in browser localStorage
